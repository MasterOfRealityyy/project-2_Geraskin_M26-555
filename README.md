## Управление таблицами

Программа поддерживает следующие команды:

- `help` — вывести справочную информацию.
- `create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...` — создать новую таблицу. Поддерживаемые типы данных: `int`, `str`, `bool`.
- `list_tables` — показать список всех созданных таблиц.
- `drop_table <имя_таблицы>` — удалить таблицу.
- `exit` — выйти из программы.

## Операции с данными 

Программа поддерживает следующие команды:

- `insert into <имя_таблицы> values (<значение1>, <значение2>, ...)` — добавить новую запись в таблицу.
- `select from <имя_таблицы>` — вывести все записи из таблицы в виде красивой таблицы.
- `select from <имя_таблицы> where <столбец> = <значение>` — вывести записи, соответствующие условию.
- `update <имя_таблицы> set <столбец> = <новое_значение> where <столбец_условия> = <значение_условия>` — обновить существующие записи.
- `delete from <имя_таблицы> where <столбец> = <значение>` — удалить записи, соответствующие условию.

## Дополнительный функционал 

- Обработка ошибок: Ошибки БД перехватываются декоратором `@handle_db_errors`.
- Подтверждение опасных действий: При удалении таблиц или записей декоратор `@confirm_action` запрашивает подтверждение `[y/n]`.
- Замер времени: Декоратор `@log_time` выводит в консоль время выполнения операций `insert` и `select`.
- Кэширование: Для команды `select` реализован механизм кэширования.
